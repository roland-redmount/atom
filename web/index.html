atom snippets

A page for checking the snippet element. Every snippet here shares one session, so what one snippet states, a later one can ask about.

Ask what two and three make. s is a variable, so it is filled in:

+ 2 + 3 = s

A variable can stand anywhere in the term, so the same table answers backwards:

+ 2 + x = 9

State a fact:

:assert foo 42 bar "baz"

And ask about it here, in a snippet that never stated it:

foo 42 bar b

A syntax error points at the character it could not read:

bogus ]] syntax

Several lines are answered in turn, as if each had been typed:

:help + 7 + 5 = s
